## 🏛️ Tentang Platform

**RUANG ISU** merupakan platform intelligence dan pemantauan isu sosial-politik yang dirancang khusus untuk memenuhi kebutuhan kader, pengurus komisariat, tim kajian, dan bidang sosial-politik GMNI. 

Platform ini bukan sekadar portal berita biasa atau chatbot generik, melainkan **Issue Intelligence Platform / Social Political Monitoring Platform** dengan fokus teritorial utama pada **Kabupaten Purwakarta (17 Kecamatan)**, **Jawa Barat**, hingga **Nasional Indonesia**.

---

## 🚀 Fitur Utama

1. **Dashboard Intelligence & Prioritas Isu**:
   - Agregasi data (Total Isu, Isu Baru, Sedang Berkembang, Prioritas Kajian, Fokus Purwakarta).
   - **Issue Priority Board** dengan kalkulasi skor *Impact*, *Evidence*, dan *Momentum*.

2. **Fact vs Claim System (Fitur Wajib)**:
   - Pemilahan ketat 3 tingkat:
     - ✅ **Terkonfirmasi**: Berdasarkan dokumen resmi & instansi berwenang.
     - ⚠️ **Klaim / Pernyataan**: Pernyataan sepihak narasumber/korporasi yang butuh audit lapangan.
     - ❓ **Belum Terverifikasi**: Desas-desus atau sinyal medsos.

3. **Panel Sumber & Credibility Index**:
   - Pembobotan reliabilitas internal (Sumber Resmi 95/100, Media Terverifikasi 85/100, Media Lokal 75/100, Media Sosial 45/100).

4. **Timeline & Momentum Perhatian Publik**:
   - Kronologi peristiwa interaktif dan grafik tren atensi masyarakat dengan analisis AI.

5. **Peta Aktor & Relasi Pemangku Kepentingan**:
   - Visualisasi jejaring posisi sikap regulator, aparat, korporasi, serikat buruh, dan paguyuban warga.

6. **Pantauan Media Sosial & Sinyal Publik**:
   - Pemantauan volume dan sentimen warganet (Instagram, TikTok, X, YouTube, Forum Warga) disertai *banner etika verifikasi*.

7. **Peta Isu Geospasial**:
   - Peta sebaran isu Indonesia dan drill-down **17 Kecamatan Kabupaten Purwakarta** (Jatiluhur, Bungursari, Wanayasa, Campaka, dll).

8. **AI Issue Analyst (Non-Generic Workspace)**:
   - 8 Modul analisis: Ringkasan Fakta, Komparasi Kontradiksi Sumber, Deteksi Celah Data, Pemetaan Aktor, 8 Dimensi Pertanyaan Kajian Dialektis, Rekomendasi Kelayakan Riset, Analisis Marhaenisme GMNI, dan Draf Bahan Kajian.

9. **Pisau Analisis Marhaenisme GMNI**:
   - Evaluasi kritis berlandaskan **Sosio-Nasionalisme**, **Sosio-Demokrasi**, **Trisakti**, dan **Keberpihakan Kaum Marhaen**.

10. **Generator Dokumen Bahan Kajian / Policy Brief**:
    - Naskah akademik 10 bab terstruktur dengan mode **Cetak Otomatis (Print-Ready)**, ekspor Markdown (.md), dan salin naskah.

11. **Global Search (`Ctrl+K` / `⌘K`) & Simulasi Peran**:
    - Mode Admin, Peneliti/Kader SosPol, Anggota GMNI, dan Publik.

## 🛠️ Teknologi yang Digunakan

- **Framework**: Next.js 15 (App Router) + React 19 + TypeScript
- **Styling**: Tailwind CSS + Custom Typography
- **Icons**: Lucide React
- **Animations**: Framer Motion & Tailwind Transitions
- **Asset**: Logo Resmi GMNI di `/public/assets/gmni/logo-gmni.png`

## 💻 Memulai Pengembangan Lokal

1. **Clone repository**:
   ```bash
   git clone https://github.com/faridnadir24-bit/GMNI.git
   cd GMNI
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Jalankan local development server**:
   ```bash
   npm run dev
   ```

4. **Buka di browser**:
   Akses `http://localhost:3000`

5. **Build untuk produksi**:
   ```bash
   npm run build
   npm run start
   ```
